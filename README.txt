모바일 최적화 온라인 타이머 사이트

- 모든 HTML 페이지는 반응형 모바일 레이아웃입니다.
- 버튼 터치 영역을 키웠고, 모바일 화면에서 프리셋 버튼과 시간 입력이 편하게 배치됩니다.
- 홈 화면에 추가 기능을 위한 기본 manifest 파일이 포함되어 있습니다. 앱스토어 앱은 아닙니다.
- 실제 도메인을 정한 후 sitemap.xml 및 robots.txt의 YOUR-DOMAIN.com을 교체하세요.
- AdSense 승인 전에는 광고 자리 표시자만 보입니다. 승인 후 Google에서 받은 코드로 교체하세요.
- 광고 승인은 보장되지 않습니다. 독창적이고 충분한 콘텐츠, 개인정보처리방침 등도 준비하세요.

배포:
1. ZIP 압축을 풉니다.
2. 모든 파일을 GitHub 저장소 최상위에 올립니다.
3. Cloudflare Pages 또는 Vercel에서 저장소를 연결합니다.
4. 도메인을 연결하고 실제 주소로 sitemap/robots 설정을 수정합니다.
